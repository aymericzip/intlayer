# Intlayer Vanilla JS Usage

## Core Philosophy

Intlayer promotes **Component-Level Content Declaration**. Instead of a massive global translation file, content is declared in `*.content.ts` files adjacent to the scripts that use them.

`vanilla-intlayer` mirrors the `react-intlayer` API without depending on a UI framework: a pub/sub singleton plus callback-based helpers.

### Declare Content

**File:** `src/app.content.ts`

```typescript
import { t, type Dictionary } from "intlayer";

const content = {
  key: "app",
  content: {
    title: t({
      en: "Welcome",
      fr: "Bienvenue",
      es: "Hola",
    }),
  },
} satisfies Dictionary;

export default content;
```

## Setup

- [Vite and Vanilla JS](https://intlayer.org/doc/environment/vite-and-vanilla.md) (bundled app)
- [Vanilla JS](https://intlayer.org/doc/environment/vanilla.md) (no bundler, standalone script generated by `intlayer standalone`)

Call `installIntlayer()` **before** any content is rendered.

## useIntlayer

`useIntlayer(key, locale?)` returns the content directly. Chain `.onChange()` to re-render when the locale changes.

```typescript
import { useIntlayer } from "vanilla-intlayer";

const title = document.querySelector("h1")!;

const content = useIntlayer("app").onChange((newContent) => {
  title.textContent = String(newContent.title);
});

title.textContent = String(content.title);
// Native attributes: use `.value`
// image.alt = content.title.value;
```

> Without a bundler, read the same helpers from the globals of the standalone bundle: `window.VanillaIntlayer` and `window.Intlayer`.

## useLocale

```typescript
import { useLocale } from "vanilla-intlayer";

const { locale, availableLocales, setLocale, subscribe } = useLocale();

const unsubscribe = subscribe((newLocale) => {
  document.documentElement.lang = newLocale;
});

setLocale("fr");
```

## Compiler

The [Intlayer Compiler](https://intlayer.org/doc/compiler.md) can extract all your content keys from your components, using one CLI command (`npx intlayer extract`) or automatically at app build.
