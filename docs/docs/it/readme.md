## Cos'è Intlayer?

La maggior parte delle librerie i18n sono o troppo complesse, o troppo rigide, oppure non sono progettate per i framework moderni.

Intlayer è una **soluzione i18n moderna** per le applicazioni web e mobili.  
È indipendente dal framework, **basata sull'IA**, e include un **CMS e un editor visuale** gratuiti.

Con **file di contenuto per ogni locale**, **autocompletamento TypeScript**, **dizionari tree-shakable**, e **integrazione CI/CD**, Intlayer rende l'internazionalizzazione **più veloce, più pulita e più intelligente**.

## 📦 Installazione

Inizia oggi il tuo viaggio con Intlayer e scopri un approccio più fluido e potente all'internazionalizzazione.

<a href="https://github.com/aymericzip/intlayer/blob/main/docs/docs/it/dictionary/content_file.md" rel="">
  <img src="https://img.shields.io/badge/Inizia-FFFFFF?style=for-the-badge&logo=rocket&logoColor=black" />
</a>

```bash packageManager="npm"
npm install intlayer react-intlayer
```

```bash packageManager="yarn"
yarn add intlayer react-intlayer
```

```bash packageManager="pnpm"
pnpm add intlayer react-intlayer
```

```bash packageManager="bun"
bun add intlayer react-intlayer
```

⚡ Avvio rapido (Next.js)

```ts
// intlayer.config.ts
import { Locales, type IntlayerConfig } from "intlayer";

const config: IntlayerConfig = {
  internationalization: {
    locales: [Locales.ENGLISH, Locales.FRENCH, Locales.SPANISH],
    defaultLocale: Locales.ENGLISH,
  },
};

export default config;
```

```ts
// app/home.content.ts
import { t, type Dictionary } from "intlayer";

const content = {
  key: "home",
  content: {
    title: t({
      en: "Home",
      fr: "Accueil",
      es: "Inicio",
    }),
  },
} satisfies Dictionary;

export default content;
```

```tsx
// app/page.tsx
import { useIntlayer } from "react-intlayer";

const HomePage = () => {
  const { title } = useIntlayer("home");

  return <h1>{title}</h1>;
};
```

## Sistema di gestione dei contenuti multilingue

Più qu'una libreria i18n, Intlayer è un **sistema di gestione dei contenuti multilingue** completo. Un CMS completo è disponibile gratuitamente all'indirizzo [app.intlayer.org](https://app.intlayer.org/?utm_source=chatgpt.com).

Intlayer collega **sviluppatori**, **copywriter** e **agenti AI** in un unico flusso di lavoro per creare e mantenere siti web multilingue senza alcuno sforzo. Intlayer sostituisce lo stack seguente in un'unica soluzione:

- Soluzioni i18n (es. `i18next`, `next-intl`, `vue-i18n`)
- TMS (Sistemi di gestione delle traduzioni) (es. Crowdin, Phrase, Lokalise)
- CMS Headless (es. Contentful, Strapi, Sanity)
