# חבילת express-intlayer

חבילת `express-intlayer` מספקת תוכנת ביניים (middleware) עבור אפליקציות Express לניהול בינאום. היא מזהה את שפת המשתמש ומספקת פונקציות תרגום.

## התקנה

```bash
npm install express-intlayer
```

## ייצואים (Exports)

### תוכנת ביניים (Middleware)

ייבוא:

```tsx
import "express-intlayer";
```

| פונקציה    | תיאור                                                                                                                                                                                                                                             | תיעוד קשור                                                                                                      |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `intlayer` | תוכנת ביניים של Express המזהה את שפת המשתמש ומאכלסת את `res.locals` בנתוני Intlayer. מבצעת זיהוי שפה מתוך עוגיות/כותרות, מזריקה את `t`, `getIntlayer` ו-`getDictionary` לתוך `res.locals`, ומגדירה מרחב שמות CLS עבור גישה לאורך מחזור חיי הבקשה. | [intlayer](https://github.com/aymericzip/intlayer/blob/main/docs/docs/he/packages/express-intlayer/intlayer.md) |

### פונקציות

ייבוא:

```tsx
import "express-intlayer";
```

| פונקציה         | תיאור                                                                                                                                                                      | תיעוד קשור                                                                                             |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `t`             | פונקציית תרגום המאחזרת תוכן עבור השפה הנוכחית. פועלת בתוך מחזור חיי הבקשה המנוהל על ידי תוכנת הביניים `intlayer`. משתמשת ב-CLS (Async Local Storage) כדי לגשת להקשר הבקשה. | [translation](https://github.com/aymericzip/intlayer/blob/main/docs/docs/he/dictionary/translation.md) |
| `getIntlayer`   | מאחזרת מילון לפי המפתח שלו מתוך ההצהרה שנוצרה ומחזירה את התוכן שלו עבור השפה שצוינה. גרסה מותאמת של `getDictionary`. משתמשת ב-CLS לגישה להקשר הבקשה.                       | -                                                                                                      |
| `getDictionary` | מעבדת אובייקטי מילון ומחזירה תוכן עבור השפה שצוינה. מעבדת תרגומי `t()`, ריבוי, markdown, HTML וכו'. משתמשת ב-CLS לגישה להקשר הבקשה.                                        | -                                                                                                      |
