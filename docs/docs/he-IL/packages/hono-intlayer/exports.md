# חבילת hono-intlayer

חבילת `hono-intlayer` מספקת תוכנת ביניים (middleware) עבור אפליקציות Hono לניהול בינאום. היא מזהה את שפת המשתמש ומאכלסת את אובייקט ההקשר (context).

## התקנה

```bash
npm install hono-intlayer
```

## ייצואים (Exports)

### תוכנת ביניים (Middleware)

ייבוא:

```tsx
import { intlayer } from "hono-intlayer";
```

| פונקציה    | תיאור                                                                                                                                                                                                                         | תיעוד קשור                                                                                                   |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `intlayer` | תוכנת ביניים של Hono המשלבת את Intlayer באפליקציית ה-Hono שלך. מטפלת בזיהוי שפה מאחסון (עוגיות, כותרות), מאכלסת את ההקשר ב-`t`, `getIntlayer` ו-`getDictionary`, ומגדירה מרחב שמות CLS לגישה פרוגרמטית במהלך מחזור חיי הבקשה. | [intlayer](https://github.com/aymericzip/intlayer/blob/main/docs/docs/he/packages/hono-intlayer/intlayer.md) |

### פונקציות

ייבוא:

```tsx
import { t, getIntlayer, getDictionary } from "hono-intlayer";
```

| פונקציה         | תיאור                                                                                                                                                                                                        | תיעוד קשור                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| `t`             | פונקציית תרגום גלובלית המאחזרת תוכן עבור השפה הנוכחית ב-Hono. עושה שימוש ב-CLS (Async Local Storage) וחייבת לפעול בתוך הקשר בקשה המנוהל על ידי תוכנת הביניים `intlayer`. ניתנת לגישה גם דרך ההקשר (context). | [translation](https://github.com/aymericzip/intlayer/blob/main/docs/docs/he/dictionary/translation.md) |
| `getIntlayer`   | מאחזרת מילון לפי המפתח שלו מתוך ההצהרה שנוצרה ומחזירה את התוכן שלו עבור השפה שצוינה. גרסה מותאמת של `getDictionary`. משתמשת ב-CLS לגישה להקשר הבקשה. ניתנת לגישה גם דרך ההקשר.                               | -                                                                                                      |
| `getDictionary` | מעבדת אובייקטי מילון ומחזירה תוכן עבור השפה שצוינה. מעבדת תרגומי `t()`, ריבוי, markdown, HTML וכו'. משתמשת ב-CLS לגישה להקשר הבקשה. ניתנת לגישה גם דרך ההקשר.                                                | -                                                                                                      |
