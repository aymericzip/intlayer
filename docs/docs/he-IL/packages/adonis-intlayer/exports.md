# חבילת adonis-intlayer

חבילת `adonis-intlayer` מספקת תוכנת ביניים (middleware) עבור אפליקציות AdonisJS לניהול בינאום. היא מזהה את שפת המשתמש ומספקת פונקציות תרגום.

## התקנה

```bash
npm install adonis-intlayer
```

## ייצואים (Exports)

### תוכנת ביניים (Middleware)

החבילה מספקת תוכנת ביניים של AdonisJS לטיפול בבינאום.

| פונקציה              | תיאור                                                                                                                                                                                                                             | תיעוד קשור                                                                                                        |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `IntlayerMiddleware` | תוכנת ביניים של AdonisJS המזהה את שפת המשתמש ומאכלסת את הקשר הבקשה בנתוני Intlayer. היא גם מגדירה מרחב שמות CLS (Async Local Storage) לגישה לאורך מחזור חיי הבקשה, ומאפשרת שימוש בפונקציות גלובליות כגון `t`, `getIntlayer` וכו'. | [intlayer](https://github.com/aymericzip/intlayer/blob/main/docs/docs/he-IL/packages/adonis-intlayer/intlayer.md) |

### פונקציות

| פונקציה         | תיאור                                                                                                                                                                      | תיעוד קשור                                                                                                |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `t`             | פונקציית תרגום המאחזרת תוכן עבור השפה הנוכחית. פועלת בתוך מחזור חיי הבקשה המנוהל על ידי תוכנת הביניים `intlayer`. משתמשת ב-CLS (Async Local Storage) כדי לגשת להקשר הבקשה. | [translation](https://github.com/aymericzip/intlayer/blob/main/docs/docs/he-IL/dictionary/translation.md) |
| `getIntlayer`   | מאחזרת מילון לפי המפתח שלו מתוך ההצהרה שנוצרה ומחזירה את התוכן שלו עבור השפה שצוינה. גרסה מותאמת של `getDictionary`. משתמשת ב-CLS לגישה להקשר הבקשה.                       | -                                                                                                         |
| `getDictionary` | מעבדת אובייקטי מילון ומחזירה תוכן עבור השפה שצוינה. מעבדת תרגומי `t()`, ריבוי, markdown, HTML וכו'. משתמשת ב-CLS לגישה להקשר הבקשה.                                        | -                                                                                                         |
| `getLocale`     | מאחזרת את השפה הנוכחית מתוך הקשר הבקשה באמצעות CLS.                                                                                                                        | -                                                                                                         |
