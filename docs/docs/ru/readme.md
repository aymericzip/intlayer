## Что такое Intlayer?

Большинство библиотек i18n либо слишком сложны, либо слишком жестки, либо не созданы для современных фреймворков.

Intlayer, это **современное решение i18n** для веб- и мобильных приложений.  
Он не зависит от фреймворка, **использует ИИ** и включает бесплатную **CMS и визуальный редактор**.

С помощью **файлов контента для каждого языка**, **автодополнения TypeScript**, **дерево-устойчивых словарей** и **интеграции CI/CD** Intlayer делает интернационализацию **быстрее, чище и умнее**.

Начните свое путешествие с Intlayer уже сегодня и ощутите более плавный и мощный подход к интернационализации.

```bash packageManager="npm"
npm install intlayer react-intlayer
```

```bash packageManager="yarn"
yarn add intlayer react-intlayer
```

```bash packageManager="pnpm"
pnpm add intlayer react-intlayer
```

```bash packageManager="bun"
bun add intlayer react-intlayer
```

⚡ Быстрый старт (Next.js)

```ts
// intlayer.config.ts
import { Locales, type IntlayerConfig } from "intlayer";

const config: IntlayerConfig = {
  internationalization: {
    locales: [Locales.ENGLISH, Locales.FRENCH, Locales.SPANISH],
    defaultLocale: Locales.ENGLISH,
  },
};

export default config;
```

```ts
// app/home.content.ts
import { t, type Dictionary } from "intlayer";

const content = {
  key: "home",
  content: {
    title: t({
      en: "Home",
      fr: "Accueil",
      es: "Inicio",
    }),
  },
} satisfies Dictionary;

export default content;
```

```tsx
// app/page.tsx
import { useIntlayer } from "react-intlayer";

const HomePage = () => {
  const { title } = useIntlayer("home");

  return <h1>{title}</h1>;
};
```

## Многоязычная система управления контентом

Больше, чем просто библиотека i18n, Intlayer - это полноценная **многоязычная система управления контентом**. Полнофункциональная CMS доступна бесплатно по адресу [app.intlayer.org](https://app.intlayer.org/?utm_source=chatgpt.com).

Intlayer объединяет **разработчиков**, **копирайтеров** и **ИИ-агентов** в единый рабочий процесс для легкого создания и поддержки многоязычных сайтов. Intlayer заменяет следующий стек в одном решении:

- i18n решения (например, `i18next`, `next-intl`, `vue-i18n`)
- TMS (системы управления переводами) (например, Crowdin, Phrase, Lokalise)
- Headless CMS (например, Contentful, Strapi, Sanity)
