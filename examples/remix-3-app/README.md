# Remix 3 + Intlayer Example

This example demonstrates how to integrate **[Intlayer](https://intlayer.org)** for seamless internationalization (i18n) in **Remix 3** applications with locale-aware routing, type-safe content declarations, safe HTML templates, and cross-runtime support across Node.js, Bun, Deno, and Cloudflare Workers.

---

## What is Remix 3?

**Remix 3** is a composable, runtime-agnostic web framework built entirely on web standards. Rather than being coupled to specific bundlers or proprietary server APIs, Remix 3 is distributed as single-purpose, composable packages:

- **`remix/fetch-router`** (or `remix/router`): Lightweight, standard-compliant routing built on the Fetch API (`Request` and `Response`).
- **`remix/html-template`**: Safe HTML template literals with automatic XSS protection and fragment composition.
- **`remix/response/html`**: Response helper utilities for serving HTML with standard HTTP semantics.
- **`remix/node-fetch-server`**: Server adapters for Node.js, while natively supporting Bun, Deno, and edge runtimes.
- **`remix/routes`**: Type-safe declarative routing.

Combined with **Intlayer** and the **`remix-intlayer`** package (a locale-routing middleware plus the same `useLocale` / `useIntlayer` / `useDictionary` hooks as `react-intlayer`, bound to the Remix request context), you get a complete internationalization system that delivers compile-time safety, automated AI translations, zero-overhead server rendering, and seamless locale routing.

---

## Features

- **Runtime-Agnostic**: Runs on Bun, Node.js, Deno, or Cloudflare Workers.
- **Declarative Content Dictionaries**: Co-locate translations alongside views (`.content.ts`).
- **Type Safety**: Autogenerated TypeScript types for autocomplete and compile-time validation.
- **Locale Routing**: Routes are declared once (`/`, `/about`); the middleware redirects `/about` to `/fr/about` for a French visitor, serves `/fr/about` from the `about` route and strips the default-locale prefix, with cookie and header fallback.
- **Safe HTML**: Server-rendered HTML templates with zero client bundle overhead.
- **AI Automation**: Built-in CLI commands to audit (`intlayer test`) and auto-fill (`intlayer fill`) missing translations.

## Step-by-Step Implementation Guide

### Step 1: Configuration

Declare supported locales in `intlayer.config.ts`:

```typescript
import { Locales, type IntlayerConfig } from "intlayer";

const config: IntlayerConfig = {
  internationalization: {
    locales: [Locales.ENGLISH, Locales.FRENCH, Locales.SPANISH],
    defaultLocale: Locales.ENGLISH,
  },
};

export default config;
```

### Step 2: Content Declarations

Declare content using `t()` in `.content.ts` files:

```typescript
// src/views/home.content.ts
import { type Dictionary, t } from "intlayer";

const homeContent = {
  key: "home",
  content: {
    title: t({
      en: "Welcome to Remix 3 with Intlayer",
      fr: "Bienvenue sur Remix 3 avec Intlayer",
      es: "Bienvenido a Remix 3 con Intlayer",
    }),
    subtitle: t({
      en: "A modern, composable web application built on web standards with full internationalization.",
      fr: "Une application web moderne et composable construite sur les standards web avec internationalisation complète.",
      es: "Una aplicación web moderna y componible construida sobre estándares web con internacionalización completa.",
    }),
    badge: t({
      en: "Composable Web Framework",
      fr: "Framework Web Composable",
      es: "Framework Web Componible",
    }),
  },
} satisfies Dictionary;

export default homeContent;
```

### Step 3: Middleware Setup

`remix-intlayer` ships a router middleware that handles the whole
internationalization layer, like the proxies of `next-intlayer` and
`vite-intlayer`:

- **Locale routing**, following `routing.mode` (`prefix-no-default` by default):
  `/about` is redirected to `/fr/about` when the visitor's stored locale or
  `Accept-Language` is French, `/fr/about` is served from the `/about` route as
  French, `/en/about` is redirected to `/about`, and `routing.rewrite` rules are
  applied both ways (`/fr/about` → `/fr/a-propos`).
- **Locale resolution**, stored in the Remix request context as
  `context.intlayer` (or `context.get(Intlayer)`).
- **Locale persistence**, through the configured cookie / header.

Register it once on the router:

```typescript
import { intlayer } from "remix-intlayer";
import { createRouter } from "remix/router";

export const router = createRouter({
  middleware: [intlayer()],
});
```

The middleware also keeps the request context in an `AsyncLocalStorage` scope,
so the hooks read the locale ambiently — same signatures as `react-intlayer`,
usable in route handlers, views and `remix/ui` components alike:

```typescript
import { useIntlayer, useLocale } from "remix-intlayer";

export const renderHomePage = () => {
  const { locale, availableLocales } = useLocale();
  const home = useIntlayer("home");
  // ...
};
```

Set `routing.enableProxy: false` in `intlayer.config.ts` to keep the locale
resolution only and handle the routing yourself.

### Step 4: Route Definitions

Define type-safe routes in `src/routes.ts`. They are declared once, without a
locale segment — the middleware serves every locale from them:

```typescript
import { route } from "remix/routes";

export const routes = route({
  home: "/",
  about: "/about",
  apiGreeting: "/api/greeting",
});
```

Links are localized with `getLocalizedPath(routes.about.href(), locale)`,
which yields `/about` for the default locale and `/fr/about` for French.

### Step 5: Server Wiring

Hook up router, middleware, and route actions in `src/server.ts`:

```typescript
import * as http from "node:http";
import { createRequestListener } from "remix/node-fetch-server";
import { createHtmlResponse } from "remix/response/html";
import { createRouter } from "remix/router";
import { intlayer, useIntlayer, useLocale } from "remix-intlayer";
import { routes } from "./routes";
import { renderAboutPage } from "./views/about";
import { renderHomePage } from "./views/home";

export const router = createRouter({
  middleware: [intlayer()],
});

router.map(routes, {
  actions: {
    home() {
      return createHtmlResponse(renderHomePage());
    },
    about() {
      return createHtmlResponse(renderAboutPage());
    },
    apiGreeting() {
      const { locale } = useLocale();
      const home = useIntlayer("home");
      return Response.json({
        success: true,
        locale,
        message: home.title,
        timestamp: new Date().toISOString(),
      });
    },
  },
});

const PORT = Number(process.env.PORT || 3000);

if (
  typeof (process.versions as any)?.bun === "undefined" &&
  process.env.NODE_ENV !== "test"
) {
  const server = http.createServer(
    createRequestListener((request) => router.fetch(request))
  );
  server.listen(PORT, () => {
    console.log(
      `🚀 Remix 3 + Intlayer server running at http://localhost:${PORT}`
    );
  });
}

export default {
  port: PORT,
  fetch(request: Request) {
    return router.fetch(request);
  },
};
```

## TypeScript Configuration

Ensure `tsconfig.json` includes the generated `.intlayer` types:

```json
{
  "$schema": "https://json.schemastore.org/tsconfig",
  "compilerOptions": {
    "moduleResolution": "Bundler",
    "module": "ESNext",
    "target": "ESNext",
    "skipLibCheck": true,
    "strict": true,
    "types": ["node"]
  },
  "include": ["**/*", ".intlayer/**/*.ts"],
  "exclude": ["node_modules"]
}
```
